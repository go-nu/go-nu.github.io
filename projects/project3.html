GONGGAN

외국인 및 국내 사용자를 위한 K-Food · K-Beauty · Location 정보 제공 웹 서비스. Java Servlet/JSP MVC 패턴으로 구현한 팀 프로젝트로, 팀장을 맡아 게시판 시스템·회원 기능·관리자 페이지 전반을 담당했습니다.

01 · OVERVIEW

프로젝트 개요

GONGGAN(공간)은 K-Food, K-Beauty, Location 세 가지 카테고리로 한국 문화를 소개하는 종합 정보 웹 서비스입니다. 사용자는 카테고리별 게시판에 글을 작성하고, 화장품 정보를 탐색하며, 네이버 지도 API와 연동된 관광지·체험 활동을 예약할 수 있습니다. 관리자 페이지를 통해 콘텐츠 전반을 관리하고 예약 현황을 통계 차트로 파악할 수 있습니다.

팀장으로서 전체 일정을 조율하고 역할을 분배했으며, 게시판 시스템 연동·회원 기능·관리자 페이지를 직접 구현했습니다. Java Servlet/JSP MVC 패턴을 기반으로 설계하여 Controller-DAO-View 계층을 명확히 분리했습니다.

03 · ARCHITECTURE

시스템 구조 및 데이터 흐름

Java Servlet/JSP MVC 패턴을 기반으로 설계했습니다. 사용자의 *.do URL 요청은 Servlet Controller가 받아 처리하고, DAO를 통해 MySQL과 통신한 뒤 JSP View로 결과를 렌더링합니다.

04 · FEATURES

담당 기능 상세

1
카테고리별 게시판 연동 (BoardController) K-Food · K-Beauty · Location 세 섹션이 하나의 BoardController 서블릿을 공유합니다. 요청 URL(*.do)과 category 파라미터로 분기 처리하여 게시글 목록·상세·작성·수정·삭제를 카테고리에 맞게 라우팅했습니다.
2
회원 기능 전반 회원가입(유효성 검사 + Bootstrap 모달 경고), 로그인/로그아웃(세션 기반), 아이디·비밀번호 찾기, 마이페이지(내 게시글·예약 내역 조회), 회원정보 수정, 회원 탈퇴(비밀번호 재확인 후 처리)를 구현했습니다. 로그인 성공·실패 결과를 Bootstrap 모달로 피드백하며, 세션 속성(id, name, gender 등)에 사용자 정보를 저장합니다.
3
관리자 페이지 — 체험 활동 관리 및 예약 현황 활동별 예약 내역 인라인 펼치기(Bootstrap Collapse), 전체 프로그램 테이블에서 예약자·연락처·인원 현황 확인, 지도 데이터(map_loc) CRUD를 구현했습니다. 통계 차트는 Chart.js의 Bar + Line 혼합 차트로 월별 전체·남성·여성 방문자 수를 시각화했습니다. 관리자 전용 공지 게시글을 food / beauty / location 카테고리별로 작성할 수 있는 진입점도 제공합니다.
4
팀장 — 역할 분담 · 페이지 디자인 · Git 관리 5인 팀의 팀장으로서 기능 단위로 역할을 분담하고 주간 진척을 조율했습니다. 전체 페이지 레이아웃과 공통 컴포넌트(header, footer, 슬라이드 배너) 디자인 가이드를 수립했으며, GitHub 저장소를 관리하고 브랜치 전략을 운영해 병합 충돌을 최소화했습니다.

05 · TROUBLE SHOOTING

문제 해결 과정

문제: 단일 게시판을 카테고리별로 분리할 때 URL 라우팅 혼선

food · beauty · location 세 섹션이 동일한 BoardController를 공유하다 보니, 카테고리 파라미터가 누락된 요청에서 기본값 처리가 없어 엉뚱한 목록이 노출되거나 리다이렉트 URL이 깨지는 문제가 발생했습니다. 컨트롤러의 모든 분기 지점에서 category 파라미터가 null이거나 빈 문자열이면 "food"로 치환하는 방어 코드를 추가했습니다. 리다이렉트 URL에도 category를 쿼리스트링으로 명시적으로 포함시켜, 목록·상세·수정·삭제 어느 흐름에서도 카테고리 맥락이 유지되도록 했습니다.

06 · RETROSPECTIVE

프로젝트 회고

✅
잘 된 점

MVC 계층 분리를 일관되게 유지하며 BoardController 하나로 카테고리별 게시판을 깔끔하게 통합했습니다. 팀장으로서 역할 분담과 Git 브랜치 관리를 주도해 충돌 없이 3주 안에 기능을 완성한 것도 뿌듯합니다.

🔧
아쉬운 점

비밀번호를 평문으로 저장한 점, 관리자 인증이 Tomcat Role 기반으로만 처리된 점이 보안 측면에서 미흡했습니다. 외부 서버 배포 경험 없이 로컬 환경에만 머문 것도 아쉽습니다.

💡
배운 점

Java Servlet/JSP MVC 패턴의 요청 처리 흐름을 직접 구현하며 웹 서버 동작 원리를 깊이 이해했습니다. Chart.js로 혼합 차트를 구성하면서 데이터 시각화의 기초도 익혔습니다.

🚀
다음 목표

클라우드 환경(AWS EC2 + RDS)에 직접 배포해 운영 경험을 쌓고 싶습니다.
