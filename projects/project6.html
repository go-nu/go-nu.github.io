IMU 센서 기반
키스트로크 다이나믹스
사용자 인증 시스템

스마트폰 IMU 센서(가속도계·자이로스코프)로 키보드 타이핑 패턴을 수집하고, 계층형 BiGRU 모델로 사용자를 자동 인증하는 행동 생체인식 연구 프로젝트입니다.

Android / Java Python / PyTorch BiGRU IMU 센서 MATLAB IEEE Sensors Journal

01 · OVERVIEW

프로젝트 개요

기존 비밀번호 기반 인증은 탈취·공유에 취약합니다. 본 연구는 스마트폰 IMU 센서 (가속도계·자이로스코프)를 활용해 키보드를 타이핑하는 동안 발생하는 미세한 진동 패턴—키스트로크 다이나믹스—을 학습하여 사용자를 자동으로 식별하는 행동 생체인식(Behavioral Biometrics) 시스템을 구현합니다.

직접 개발한 Android 데이터 수집 앱으로 좌손·우손·양손 3개 세션의 IMU 데이터를 구축한 뒤, 두 BiGRU 모델을 직렬 연결하는 멀티모달 캐스케이드 파이프라인으로 (1) 타이핑 손 방향 3-class 분류 → (2) 본인 여부 이진 인증을 수행합니다. 본 연구는 IEEE Sensors Journal에 투고 중입니다.

02 · SCREENS

주요 화면 및 결과

캐스케이드 BiGRU 모델 전체 구조 IMU 수집부터 전처리·피처 추출·두 BiGRU 모델의 직렬 연결까지 전체 파이프라인 구조를 나타냅니다.
Model 1 — 손 방향 분류 결과 BiGRU가 좌손·우손·양손 타이핑을 3-class 분류한 학습 손실 및 정확도 추이입니다.
Model 2 — 사용자 인증 결과 Model 1 출력을 피처로 추가한 BiGRU가 본인/타인을 이진 분류한 학습 결과입니다.

03 · ARCHITECTURE

시스템 구조 및 데이터 흐름

Android 앱에서 수집한 IMU 로그가 전처리·피처 추출을 거쳐 두 BiGRU 모델을 순차적으로 통과하는 계층형 멀티모달 파이프라인입니다. Model 1의 손 방향 분류 결과가 Model 2의 입력 피처에 직접 결합됩니다.

04 · FEATURES

주요 구현 내용

1
Android IMU 데이터 수집 앱 가속도계·자이로스코프를 SENSOR_DELAY_GAME 주기로 샘플링하며 키 입력 이벤트(ASCII 코드)와 타임스탬프를 동기 기록합니다. 좌손·우손·양손 3개 입력 필드와 3개 chapter를 자동 전환하여 체계적인 데이터를 수집합니다.
2
전처리 — 세션 분리 및 선형 보간 패딩 원시 로그에서 L/R/Both 타이핑 세션을 ASCII 기준으로 자동 분리하고, 가변 길이 시계열을 최대 길이에 맞춰 7개 키 구간별로 균등 보간합니다. 배치 학습에 필요한 동일 크기의 입력 텐서를 생성하면서 타이핑 리듬 정보를 최대한 보존합니다.
3
Model 1 — BiGRU 타이핑 손 방향 분류 7차원 IMU 시계열(key ASCII + timestamp + ax, ay, az, gx, gy)을 입력으로 받는 양방향 GRU(hidden=32, layers=4)로 좌손(0)·우손(1)·양손(2) 3-class 분류를 수행합니다. CrossEntropyLoss와 Adam(lr=1e-3)으로 학습합니다.
4
Model 2 — BiGRU 사용자 이진 인증 키스트로크별 IMU 6축의 95th/5th 백분위수 통계 + 키 유지 시간 + Model 1 출력을 결합한 15차원 피처 벡터를 BiGRU(hidden=8, layers=4)로 학습합니다. Sigmoid + BCELoss로 본인(0) / 타인(1)을 이진 분류하며, Model 1의 손 방향 컨텍스트가 인증 정확도를 향상시킵니다.
5
MATLAB IMU 시각화 및 데이터 검증 수집된 IMU 데이터를 관성 좌표계로 변환하여 3D 자세 시각화 및 각 센서 신호 플롯을 제공합니다. 가속도계 캘리브레이션 파일(acce_calib.txt)을 자동 적용하여 수집 데이터의 품질을 검증합니다.

05 · TROUBLE SHOOTING

문제 해결 과정

문제: 가변 길이 키스트로크 시계열의 배치 학습 불가

사용자마다 타이핑 속도가 달라 동일 키에 대한 IMU 시퀀스 길이가 제각각이었습니다. PyTorch DataLoader는 동일한 배치 크기를 요구하기 때문에 단순 제로 패딩만으로는 의미 없는 0값이 학습 신호에 혼입되는 문제가 있었습니다. 전체를 단순 패딩하는 대신, 7개 키 구간(chapter에 해당하는 ASCII 그룹)별로 목표 길이를 비례 배분한 뒤 numpy.interp로 열(column)마다 독립적으로 선형 보간하여 원래 타이핑 리듬을 최대한 보존했습니다. 이 방식으로 배치 학습 가능한 고정 크기 텐서를 생성하면서 정보 손실을 최소화했습니다.

문제: 타이핑 손 방향 정보를 인증 모델에 반영하는 방법

사용자 인증 모델(Model 2)이 타이핑 손 방향을 모르면 손에 따라 달라지는 IMU 패턴 차이를 구분하지 못해 인증 정확도가 낮아졌습니다. 두 모델을 완전히 분리하면 이 맥락 정보가 유실됩니다. Model 1의 추론 결과(L/R/Both 레이블)를 각 키스트로크 데이터 행에 열로 직접 concat한 뒤 백분위수 통계 피처를 추출하여 Model 2의 입력 피처(15-dim)에 포함시켰습니다. 이렇게 하면 Model 2가 손 방향 컨텍스트를 피처로 함께 학습할 수 있어 동일 사용자라도 손에 따른 IMU 패턴 변화를 보정할 수 있습니다.
